# Product Requirements Document

Build a simple notes app that lets users see saved notes and create new notes.

## Goals

- Users can view a list of saved note titles.
- Users can create a new note with a title.
- The app validates empty titles before creating a note.

## Constraints

- Do not add authentication in this sample.
- Keep storage local to the app unless a later PRD introduces a backend.
- Include focused tests for listing notes and creating notes.
